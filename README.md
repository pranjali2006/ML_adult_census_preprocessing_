\# ML CIE 1 – Adult Census Income Dataset



\## Project Overview

This project focuses on data cleaning, exploratory data analysis (EDA), and preprocessing of the Adult Census Income dataset using Python.



\## Tasks Performed

\- Dataset inspection and understanding

\- Missing value analysis and handling

\- Duplicate checking

\- Outlier detection using IQR

\- Exploratory Data Analysis

\- Categorical data encoding

\- Numerical feature standardization



\## Tools and Libraries

\- Python

\- Pandas

\- NumPy

\- Matplotlib

\- Seaborn

\- Scikit-learn

\- Google Colab



\## Files

\- `ML\_CIE-1.ipynb` – Project notebook

\- `adult.csv` – Dataset file
